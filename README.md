# Ferro Bocce

Full-colour Python 3 neon court-roll arcade for [ElbowOS](https://x.com/ElbowOS).

Aim the ferrite sphere and roll it up a rust-gold court. Bank off coral bumpers, knock jack orbs into lime wells, chain combos.

A / D aim. Hold Space / W to charge, release to roll.

## Play

```
pip install -r requirements.txt
python3 ferro_bocce.py --play
```

## Record a 9:16 reel

```
python3 ferro_bocce.py --record
```
